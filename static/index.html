Connect YouTube Music

The player reads your library with the same login your browser uses. Requests only go to YouTube, nothing else leaves this computer.

  1. Open a private window and sign in at music.youtube.com.
  2. Press F12, open the Network tab and type browse in its filter. Click Library on the page so a request appears.
  3. Right-click that request, choose Copy, then Copy as cURL (bash). In Firefox, use Copy Value, then Copy Request Headers instead.
  4. Paste it below, then close the private window.

The private window matters: it stops YouTube from rotating the cookies this app reuses for playback.
