Connect YouTube Music

The player reads your library with the same login your browser uses. Requests only go to YouTube, nothing else leaves this computer.

  1. Open a private window and sign in at music.youtube.com.
  2. Press F12, open the Network tab and type browse in its filter. Click Library on the page so a request appears.
  3. Right-click that request, choose Copy, then Copy as cURL (bash). In Firefox, use Copy Value, then Copy Request Headers instead.
  4. Paste it below, then close the private window.

The private window matters: it stops YouTube from rotating the cookies this app reuses for playback.

Songs won't play, or "Sign in to confirm you're not a bot"?

Playback is more reliable with its own cookie file, which YouTube rotates much less:

  1. Open a new private window, sign in at youtube.com, then in that same window open youtube.com/robots.txt. Keep it the only tab.
  2. With a cookies.txt extension (for example "Get cookies.txt LOCALLY"), export the cookies for youtube.com.
  3. Close the private window right away.
  4. Save the file as cookies.txt in the Onion folder (next to app.py) and restart the player. Playback then uses that file instead of the pasted headers. Redo it if playback fails again, and don't copy it to another computer.
